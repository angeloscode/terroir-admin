# Терруар Чёрного моря

Главная страница проекта о коллекции авторских вин, в которой терруар раскрывается как вкус конкретного места. Интерфейс собран на Astro, стили и интерактивы не зависят от клиентского фреймворка, production-сборку отдаёт Nginx.

## Локальный запуск

Production-вариант в Docker:

```bash
docker compose up -d --build
```

После запуска сайт доступен по адресу [http://localhost:8080](http://localhost:8080). Проверка состояния контейнера:

```bash
docker compose ps
```

Режим разработки:

```bash
npm ci
npm run dev
```

По умолчанию dev-сервер открывается на [http://localhost:4321](http://localhost:4321).

## Проверки

```bash
npm run check
npm run build
```

## Структура

- `src/components` — независимые секции страницы и интерактивные блоки;
- `src/assets` — локальные визуальные материалы и шрифтовые зависимости сборки;
- `public/media` — исходное фоновое видео;
- `nginx.conf` — production-раздача статики и byte-range для видео;
- `compose.yml` — локальный контейнер, пригодный для последующего переноса в Portainer.

Изображения терруаров, бутылок и редакционных материалов сейчас являются осмысленными визуальными заглушками. Перед публикацией их нужно заменить утверждёнными фотографиями и предметной съёмкой, не меняя разметку секций. Контакты, точки продаж и фактические характеристики вин также ожидают подтверждённых данных.
